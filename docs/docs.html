Documentation

How to go from plant documents to a carbon compliance report for the EU carbon border tax (CBAM). Goods covered today: screws, bolts and nuts (CN 7318).

Getting started

  1. Open the CBAM dashboard. No account is needed.
  2. On Documents, drop your files in, or press Load sample documents to try it with made-up data.
  3. Under Check what we read, compare each value with its source line, fix anything wrong, and confirm.
  4. Watch the checklist. When every required item is done and confirmed, Create carbon compliance report unlocks.
  5. Check Dashboard for your numbers and the biggest gap, add a Monthly log, and record verified mill values under Mills.

Required documents

DocumentWhat we readNeeded
Mill test certificateThe mill that made the steel, heat numbers, tonnes if printedRequired, one per heat
Steel purchase invoiceHeat numbers and tonnes. The seller may be a trader, so it never sets the millRequired when a certificate has no tonnes
Fuel invoiceFuel type and quantity (LPG, diesel, natural gas)Required, or the monthly log
Production or dispatch recordTonnes of goods made, CN codeRequired, or the monthly log
Monthly fuel and output logOpening stock, bought, closing stock, outputRecommended

Heat numbers match even when written differently, for example BR-148 and br 148. If two documents disagree, the first value is kept and the conflict is listed for you to check.

Check and confirm

AI can misread a file. So nothing counts toward your number as final until a person confirms it.

  • Each uploaded file becomes a card with the values we read, the line they came from, and a link to the original.
  • Fix any value, or change what the file is (for example from "Other" to "Fuel invoice"), then press Confirm. Confirm all as read accepts everything unchanged.
  • Every correction is recorded. The report lists what was changed, marks edited sources, and the CSV flags them.
  • A wrong file can be removed. Its figures leave your number at once.
  • The report stays locked until every file is confirmed.

How the number is calculated

AI only reads documents. Every number below is calculated by fixed rules in calc.py.

embedded emissions per tonne = (direct emissions + Σ steel tonnes × steel value) ÷ output tonnes
  • Direct emissions: fuel used × emission factor. LPG 2.985 tCO2 per tonne, diesel 3.186 tCO2 per tonne, natural gas 0.00195 tCO2 per m3.
  • Steel value: the mill's verified value when it has shared one. Otherwise the EU default for Indian wire rod, 4.3 tCO2 per tonne before the mark-up. This default comes from a secondary source and is not yet confirmed against the EU table.
  • Mark-up on defaults: 10% in 2026, 20% in 2027, 30% from 2028.
  • Indirect emissions (electricity) are not counted for iron and steel goods.

The importer's cost on the dashboard uses €75 per tCO2 and the payable share of the charge: 2.5% in 2026, 5% in 2027, 10% in 2028, 22.5% in 2029, 48.5% in 2030, 61% in 2031, 73.5% in 2032, 86% in 2033 and 100% from 2034.

Monthly log

Invoices show fuel bought, not fuel burned. Log each month: fuel used = opening stock + bought − closing stock. The log replaces invoices for a fuel only when the logged purchases match the invoices within 0.5%, so a half-filled log never lowers your number. Output from the log replaces dispatch records once 12 months are logged.

Mills

Most of a bolt's emissions come from the steel. When a mill shares a verified value, record it under Mills. Every plant that buys from that mill moves from the penalty default to the actual value. The network simulation shows how fast that spreads.

The report

The carbon compliance report has a summary, the method, every figure with the document and line it came from, who checked the values and what they changed, the open checks and gaps, and space for the plant and the verifier to sign. Print it or save it as a PDF. Download EU supplier template gives the same figures as a CSV for your EU buyer.

The report is a draft. An accredited verifier must check and sign it before it is used in a CBAM declaration.

Run your own copy

The code is on GitHub under the MIT license. It needs Python 3.10 or later and no packages.

python3 server.py                       # http://localhost:8000
GEMINI_API_KEY=your-key python3 server.py   # read real PDFs and photos
VERTEX_PROJECT=your-project python3 server.py   # Gemini on Vertex AI, Mumbai

The README covers deploying to Google Cloud Run.

Data and privacy

  • This website: the app runs entirely in your browser. Files you add are not sent anywhere and are gone when you close the tab.
  • Your own server: files stay in its memory and are cleared on restart. With Gemini switched on, each document is sent to Google for reading.

Limits

  • The website demo reads text documents in the sample format only. Real PDFs and photos need a server with Gemini.
  • The steel default value is not yet confirmed against the official EU table.
  • Only one product group (CN 7318) and one output figure per plant.
  • There are no user accounts yet. Each session starts empty.
