Questions

Is the report approved by the EU?

No. It is a draft that an accredited verifier checks and signs. We prepare the data, sources and gaps so the verifier spends less time on it.

Does AI decide our emissions number?

No. AI only reads the documents. A fixed, versioned set of rules does every calculation, and each figure links back to its source.

Which documents do I need?

Mill test certificates for each steel heat, the tonnes for each heat (from certificates or invoices), fuel records and a production record. The documentation lists them.

Where is my data kept?

In the free demo, files stay in your browser. The hosted app is designed to run on Google Cloud in Mumbai so plant data stays in India.

Can I try it without signing up?

Yes. Open the app, load the sample documents and create a report. No account needed.
